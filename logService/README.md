# logService

将 QQ 协议端上报的 **消息与通知事件** 格式化为可读一行日志，写入应用日志（由 `main` 的 `logback-spring.xml` 统一落盘）。

## 职责

`LogPlugin` 继承 `CQPlugin`，对下列事件构造日志并 `log.info`，**一律返回 `MESSAGE_IGNORE`**，不拦截、不改变业务插件行为。

| 事件 | 日志前缀示例 |
|------|----------------|
| 收到私聊 / 群聊消息 | `收到 <- 私聊消息` / `收到 <- 群聊消息` |
| 机器人发出的私聊 / 群聊 | `发送 -> 私聊消息` / `发送 -> 群聊消息` |
| 群文件上传 | `发现 <- 群聊文件` |
| 群管理员变动 | `发现 <- 群管理员变动` |
| 退群 / 加群 | `收到 <- 退群` / `收到 <- 加群` |
| 群禁言 / 解禁 | `发现 <- 群禁言` |
| 好友增加、好友请求 | `发现 <- 好友增加` / `收到 <- 添加好友` |
| 加群邀请 / 入群申请 | `收到 <- 加群邀请/请求` |

每条日志前缀为 `[机器人昵称(QQ)] |`，群相关日志包含 `[群名(群号)]` 与 `[成员昵称(QQ)]`；消息正文经 HTML 反转义。禁言时长会格式化为「天/小时/分钟/秒」。

## 插件顺序

在 `application.yml` 的 `spring.cq.plugin-list` 中通常 **放在首位**，以便后续插件处理同一事件前已有完整访问日志。

## 配置

本模块无独立 `application-*.yml`；日志级别与文件路径由 `main` 的 `logging.config`（`logback-spring.xml`）控制。

## 依赖

- `spring-cq`（经 `utils` 传递）：`CoolQ` API、`CQPlugin`、事件类型
